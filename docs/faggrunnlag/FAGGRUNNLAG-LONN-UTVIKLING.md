# Faggrunnlag – Lønn og utvikling

## Kjerneprinsipper
- Skill mellom selve utfallet og hvordan beslutningen/prosessen forklares.
- Unngå å love lønn, stilling eller forfremmelse som lederen ikke har myndighet til å beslutte.
- Vær oppmerksom på krav til likebehandling og diskrimineringsvern.
- Gi saklige forklaringer og mulighet for spørsmål.

## Føring for KI
KI-en skal støtte tydelig og respektfull kommunikasjon og markere når konkrete rettigheter eller beslutningsgrunnlag må kvalitetssikres mot HR/regler.
