# Faggrunnlag – Livssituasjoner

## Kjerneprinsipper
- Lederen bør fokusere på arbeidssituasjon, funksjon, behov og mulige tilpasninger, ikke grave i private eller medisinske detaljer.
- Medarbeideren bestemmer i stor grad hvor mye privat informasjon hen ønsker å dele.
- Tilrettelegging og støtte må vurderes konkret og innenfor virksomhetens rammer.
- Samtalen skal være respektfull, åpen og uten diagnose eller spekulasjon.

## Føring for KI
KI-en skal ikke etterspørre diagnose eller intime private detaljer. Den skal hjelpe lederen med arbeidsrelaterte behov, grenser, spørsmål og videre oppfølging.
