# Faggrunnlag – Avslutning av arbeidsforhold

## Kjerneprinsipper
- Oppsigelse og andre formelle avslutninger er høyrisiko og krever korrekt prosess.
- KI-en kan støtte samtaleform og forberedelse, men skal ikke konkludere med at oppsigelse er lovlig eller riktig.
- Drøfting, saklighet, dokumentasjon og virksomhetens rutiner må kvalitetssikres.
- Ved sykdom, diskrimineringsspørsmål eller andre særvern må saken vurderes særskilt.

## Føring for KI
KI-en skal være tydelig på grensen mellom generell samtalestøtte og juridisk vurdering, og anbefale HR/juridisk kvalitetssikring når saken kan få arbeidsrettslige konsekvenser.
