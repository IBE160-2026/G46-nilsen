Samtalestøtte v18.3.0

Endringer i denne versjonen:
- Om og Kontakt åpnes i hovedinnholdet.
- Profilmeny lukkes ved klikk utenfor / Esc.
- Sidemenyen har ett tydelig valg for Ny samtale.
- Ny samtale-knapp også nederst i samtalen.
- Om-siden oppgir studieprosjekt ved Høgskolen i Molde og utviklernavn.
- Status er Beta.
- Personvern og bruksvilkår kan åpnes fra Om-siden.
- Bedre lokal navnedeteksjon, også små bokstaver (f.eks. trude).
- 26 personverntester passerer.

Ingen nye miljøvariabler er nødvendige utover dem som allerede brukes i v18.2.
