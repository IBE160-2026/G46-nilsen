SIMULATOR LIVE-TEST – RUNDE 2

   - test-simulation-ai-round2.js
   - SIMULATION-TEST-CASES-ROUND2.json

   npm start

   node test-simulation-ai-round2.js

Rapporten havner i:
test-results/
